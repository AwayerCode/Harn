# 系统设计文档格式

共同格式与检查入口见[产物规范](../../references/standards/artifacts.md)；下文只解释本类产物的使用与内容要求。

本文仅用于采用 Markdown 系统设计的项目；YAML 项目按共享模块架构规范维护结构，不重复生成下述结构表格，独立协议仍按实际契约检查。

## 两份产物

系统设计保存系统结构与技术选型；接口协议保存数据协议，覆盖模块、外部能力和持久化边界。文件名称、文档类型和默认路径沿用共同 schema，不因命名把协议缩成调用说明。已有项目沿用权威位置。

业务模型的格式与校验由共同产物规范维护。共同格式不复制到各模块，也不修改业务模型。

## 最小结构

新系统设计依次包含：文档信息、设计依据与范围、责任分层、模块与依赖、状态与资源所有权、关键协作路径、横切基础设施与运行组装、代码结构映射、技术选型、待确认问题。

新接口协议依次包含：文档信息、范围与权威来源、公共数据、协议索引、协议定义、待确认问题。

只有一个一级标题。二级标题依契约保留，细分内容使用三级及以下标题；标题前后留空行，不跳级。文件末尾恰好一个换行。文档信息采用“字段、值”表，字段依次为类型、任务、范围、依据、状态；状态为草案、待验收或已验收，不代替技术决策状态。必需章节非空，不留模板占位符。

## 系统结构与技术选型

责任分层说明业务责任与运行时协作，另行明确代码依赖方向。模块表记录模块、责任层、职责、公开能力、允许依赖和能力来源；状态或资源表记录所有者、作用域、修改权和生命周期。关键协作路径引用具体协议，横切基础设施和运行组装说明各自职责。代码结构映射记录设计责任、代码位置、公开入口和依赖约束，可以使用计划位置，不要求生成完整文件树。

技术选型记录技术项、选择、理由与取舍、决策状态。明确区分用户已确认、设计建议和待确认，不预设框架、数据库或进程模型。

## 数据协议

公共数据定义或引用数据语义、标识、字段、关系、合法状态、不变量和权威来源。协议索引明确协议标识、能力、提供方、调用方、边界类型和交互方式。持久化边界按实际责任主体说明，例如代码版本与存储数据，不虚构模块调用。

每项协议使用三级标题和“字段、值”表，字段依次为：协议标识、提供方、调用方、边界类型、交互方式、输入与输出、数据语义与前置条件、状态变化与副作用、失败语义与责任、交互约束、演进规则、验证依据。字段用于确保评估核心语义，不要求为每个接口添加事务、重试或版本机制。简单语义直接说明；无关维度注明不适用及原因，必要但未解决的内容列入待确认问题。

复杂类型放在带语言标识的代码块中，表格引用其位置。详细协作约束可写在正文或四级标题下，不用简短表格替代完整约定。验证依据说明可观察条件或证据来源，不展开测试计划。

## 脚本检查的表达约定

本约定让 `swe-cli design` 能核对显式关系，不要求在文档中嵌入代码或新建额外文件。

- 模块列使用唯一稳定名称或标识；责任层使用交互层、业务编排层、业务能力层、技术实现层、横切基础设施、运行组装。实际目录名不受限制。
- 允许依赖列填写模块标识，多个标识用顿号、逗号或分号分隔，无依赖填写“无”。通过抽象边界依赖时用 `抽象:协议标识`，对应协议须存在且调用方包含当前模块。代码依赖与运行时调用不同，抽象引用不会被当成对具体实现的直接依赖。
- 状态或资源使用唯一标识；所有者填写一个模块，修改权填写模块标识列表或“无”。代码结构映射的设计责任填写模块标识列表，每个模块至少有一项映射；目录可为计划位置。
- 协议标识使用字母、数字、点、下划线或连字符；协议索引和定义一一对应，提供方、调用方、边界类型、交互方式一致。
- 协议参与者引用模块标识。外部边界允许使用 `外部:名称`，持久化边界允许使用 `存储:名称` 表达非模块主体；每项协议至少有一个当前系统的模块参与。前缀只表达责任边界，不代替正文中的供应方和持久化语义。
- 关键协作路径使用 `协议:标识` 引用实际协议；存在协议时至少有一个显式路径引用。脚本检查引用存在，不证明路径覆盖全部业务。
- 技术选型的决策状态使用用户已确认、设计建议、待确认；脚本只检查标记合法，不证明用户确实确认过。
- 两份产物使用本地 Markdown 链接相互引用。无需状态、选型或跨边界协议时保留章节，以“不适用：”说明理由；模块及代码映射不能用“不适用”绕过责任检查。

一致性脚本检查重复或悬空引用、依赖环、平级业务能力依赖、业务对具体技术实现的直接依赖、状态归属、模块代码映射、协议索引与定义、路径引用及相互链接。它不分析自然语言的业务含义，也不扫描源码或验证技术可行性。

## 校验

校验器检查章节、必需表格及字段、元信息、占位符、代码围栏和本地链接。使用配套 CLI，只读检查不生成缓存或报告。退出码 0 为格式通过，1 为格式违规，2 为读取或参数错误。

共享校验入口为 `swe-cli documents`。内容检查以 `workflow.md` 的三项职责和交付检查为准；当前没有实现时，不宣称运行行为经过验证。
