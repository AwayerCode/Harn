# 测试设计产物说明

格式与校验见[共同产物规范](../../references/standards/artifacts.md)。本模块的输入输出清单只引用共同 schema，`assets/` 保存本类模板；项目沿用已有权威位置，具体内容按工作流审查。

本文规定测试设计的表达；测试领域还可维护本范围的测试代码和测试配置，生产代码与其他领域设计只读。协议字段引用模块设计的权威定义，不在本模块另行制定接口格式或业务语义。

## 对应关系检查

风险标识唯一；场景引用可用 `场景:标识`，对应定义使用 `### 场景:标识`。自然语言场景保留并人工核对；显式引用与定义检查完整标识，字符与分隔方式见工作流。重复风险或场景标识、非法或空标识、悬空场景引用报错，不截取有效前缀后通过。 [artifacts 检查](../../references/cli.md) 的调用节点和失败处理见 [领域入口](../SKILL.md)。脚本输出错误、已检查关系及未自动验证范围；退出码 0 不证明专业语义正确，内容审查仍需执行。
