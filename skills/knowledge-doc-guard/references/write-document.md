# 写作文档

新增和修改文档遵循同一套写作规则。先判断内容层级和中心问题，再决定内容范围；不能因为操作方式或文档名称不同而改变写作方法。

## 写入条件

只有用户明确要求保存、记录、写入、整理、更新、归档或沉淀时，才允许新增或修改文件。

如果用户只是给出路径、主题、观点、片段、问题或判断，默认只分析，不写入文件。

用户提供已经确认的成稿并要求保存时，以该成稿为权威内容，默认原样或最小整理写入，不主动扩写。

## 写作方法

所有文档都围绕一个可复用的核心认知组织内容。只写必要内容，不主动扩写，也不因追求简洁而删减已有有效内容。

只回答：

1. 核心判断是什么。
2. 必要概念是什么。
3. 概念之间有什么关键关系。
4. 能够得出什么行动结论。

写作规则：

1. 先写判断，一篇文档只解决一个中心问题。
2. Knowledge 是个人知识库，不做面向外部读者的防御性表达。
3. 一个概念只定义一次，不用没有新增含义的段落机械重复同一句话。
4. 保留核心立场、核心判断、必要概念、关键关系、行动结论和防止误解的必要边界。
5. 每个章节优先只写一个定义或判断，以及最短的关系说明。
6. 公式、列表、流程、案例和比喻只是可选表达方式；只有确实比自然语言更清楚或承载不可替代内容时才使用。
7. 多个项目能够被一个上位概念概括时，不展开为清单。
8. 案例服务概念，不替代概念；只保留核心机制、关键结果，以及它如何验证或应用当前模型。
9. 删除不影响模型成立的属性清单、分析问题、重复解释、过细分类、案例背景和属于其他专题的展开。

内容层级只决定表达范围：高层文档表达知识体系的核心认知，具体文档表达其中一个问题的核心认知。必要细节放入对应层级，不改变写作方法。

简化已有文档时，先概括原文核心，再提取核心判断、必要概念、关键关系和行动结论。修改后再次概括；核心主张和行动结论不变，且每段都承载不可替代内容，才算简化完成。

## 内容价值检查

有效知识必须直接服务文档的中心问题，并产生能够改变理解、判断或行动的认知增量。认知增量至少形成一种结果：明确概念区分，揭示关系或因果，提供推导、方法或证据，约束判断与行动，或者说明必要边界。

逐段检查：

1. 是否直接服务文档的中心问题？
2. 形成了什么新的区分、关系、因果、约束、方法、证据或行动影响？
3. 删除后会损失什么认知或行动能力？
4. 是否已经由标题、引用、列表或其他段落表达？

正确、完整或语义独立不构成保留理由。无法指出认知增量，删除后不会损失理解、判断或行动能力，或者只是重复已有内容的段落，应删除或合并。有认知价值但偏离中心问题的内容，应迁移到对应文档。

无认知价值内容和解释性铺垫不受无损保留约束。以下内容直接删除：

- 介绍主题或说明下文将讨论什么；
- 复述标题或为列表增加没有新含义的引导句；
- 只用于承上启下或说明文档结构；
- 只为照顾外部读者而补充的显然事实或背景；
- 在章节或文档结尾换一种说法重复已有结论；
- 只展开术语字面含义、常识或普遍正确结论的定义与说明；
- 可以套用于大量主题，没有形成当前领域特定约束的通用原则；
- 罗列属性、组成或步骤，但后文没有使用这些内容建立模型、推导或行动方法。

根据句段承担的实际作用判断，不能只按特定词语机械删除。

## 默认无损整理

用户只说“整理”“优化”“梳理”时，默认不压缩已有完整知识。

完整知识通常同时包含：

1. 核心框架与结论；
2. 具有认知价值的独立判断；
3. 因果链和推导过程；
4. 方法、步骤和行动原则；
5. 细节、案例和经验来源；
6. 适用边界和反例；
7. 具有认知作用或表达力量的比喻、概念和判断句。

修改前列出这些内容，修改后逐项核对。不能因为核心框架仍然存在，就认定文档没有发生知识损失。

“无损保留”只限制删除和压缩，不构成新增解释、推导、案例或结构的授权。

可以直接删除的内容仅限：

- 完全重复且没有新增含义的文本；
- 正确但没有带来认知增量的常识、定义和通用原则；
- 只承担介绍、引导、过渡或重复总结作用的解释性铺垫；
- “好的”“你说得对”“接下来总结”等纯对话外壳；
- 空行、格式残片和确定没有信息量的噪音。

其他删减必须由用户明确授权。内容放错位置时迁移，不删除；事实有误时修正对应句，不删除其余推导。
