# 系统设计兼容入口

架构层次、依赖、运行边界与技术选型使用[系统架构设计](../swe-architecture-design/workflow.md)；模块划分、状态归属、数据协议、质量指标与验收条件使用[模块与契约设计](../swe-module-design/workflow.md)。

仅做路由，不维护第二套规则。已有系统设计及接口协议的类型与项目位置继续使用；共享文档按章节划分维护责任。旧格式校验命令继续可用，读取共同 schema。
