# Markdown 格式

新增或修改 Knowledge 文档时，必须严格遵守本规范。

## 标题

- 每篇只保留一个一级标题。
- 标题层级不要跳跃。
- 标题不编号，不使用 `## 一、`、`## （一）`、`### 1.` 等形式。
- 标题不加粗，不使用加粗文本代替标题。
- 标题末尾不加冒号或句号。
- 目录和文件名已经负责排序，正文标题只表达语义。

## 列表

- 无序列表统一使用 `-`。
- 主层级列举、执行步骤、阶段、类型和条件使用有序列表，编号使用连续的 `1. 2. 3.`。
- 有序列表的下一层说明使用无序列表。
- 列表符号后只保留一个空格。

## 核心判断

- 独立成行的核心判断、公式和关系模型使用引用 `>`。
- 加粗只用于句子内部的关键词，不使用整行加粗。
- 不用代码块表达概念模型、关系式和判断句。

## 分隔与空行

- 标题、段落、列表、引用和代码块之间保留一个空行。
- 不连续堆叠多个空行。
- 不使用 `---` 水平分隔线，使用标题层级表达结构。
- 文件末尾保留一个换行。

## 代码与表格

- 命令、路径、文件名和代码符号使用行内代码。
- 真实代码和命令使用带语言标识的代码块。
- 不使用 `text` 代码块；普通文本用段落、列表或引用表达。
- 表格只用于字段映射和明确比较，不用于普通段落排版。
