# 交互规范产物说明

格式与校验见[共同产物规范](../../references/standards/artifacts.md)。本模块的输入输出清单只引用共同 schema，`assets/` 保存本类模板；项目沿用已有权威位置，具体内容按工作流审查。

本模块只维护自己负责的设计，不修改其他设计、代码、测试或配置。协议字段引用模块设计的权威定义，不在本模块另行制定接口格式或业务语义。

## 对应关系检查

公共能力可用 `协议:标识`、唯一能力名称或 `界面:动作` 表达；显式引用按完整标识检查，非法、空或悬空协议是错误，不能截取有效前缀后通过；标识字符与分隔方式见工作流。无法唯一识别的自然语言能力及纯界面动作进入人工核对。 [check_artifacts.py](../../scripts/check_artifacts.py) 的调用节点和失败处理见 [workflow.md](../workflow.md)。脚本输出错误、已检查关系及未自动验证范围；退出码 0 不证明专业语义正确，内容审查仍需执行。
