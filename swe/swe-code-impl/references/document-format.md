# SWE 文档产物规范

## 产物与存放

本 Skill 的 `references/artifact-contract.json`（如有）定义输出文档格式，`references/input-contract.json`（如有）定义接受的输入文档格式，`assets/` 保存输出模板。使用本 Skill 自带的 `scripts/validate_documents.py` 校验，运行依赖只有 Python 3 标准库，文档格式校验不借用其他模块契约，范围及对应关系检查按工作流使用 SWE 包内共享脚本。输入与输出契约的适用类型以本 Skill 的实际文件为准。

默认路径用于新项目的组织建议。已有项目保留明确的权威位置，通过 `--file` 指定实际文档；文档内容必须遵守所选契约，不强制搬迁仓库。模板中的占位符必须替换，未填模板故意不能通过校验。

本 Skill 只读校验输入文档，不创建、改写或移动任何文档；业务与技术模块代码及工程文件是 Implementation 的产物。需要改设计时停止相应实施并反馈。

## 文档结构

每篇文档只有一个一级标题，标题必须与机器契约一致。二级章节必须完整、名称准确且顺序一致，不允许省略、重复或新增二级章节。细分内容使用三级及以下标题，不跳级。标题前后保留空行，文件末尾恰好一个换行。

文档信息固定使用“字段、值”两列表格，字段顺序为类型、任务、范围、依据、状态。

- 类型使用契约中的类型标识。
- 任务填 Issue 链接、任务标识或明确目标；不要求为纯讨论创建 Issue。
- 范围说明此次文档负责的系统、模块、版本或变更。
- 依据引用实际使用的需求、业务模型、设计或协议。
- 状态只用草案、待验收、已验收。状态记录文档验收情况，不替代 Issue 任务状态。

每个必需章节必须有内容。契约指定的表格必须保留准确列名、列顺序和非空数据行。表格单元格内不使用未转义的竖线；复杂代码放到带语言标识的代码块，表格引用其位置。

不适用的章节仍保留标题，正文以“不适用：”说明具体原因；这可替代该章节的表格，但不能替代文档信息。缺少设计或尚未执行不是不适用，要明确记录待确认、未执行或阻塞。校验器只能检查原因是否填写，原因是否成立由 Review 判断。

## 接口协议

协议索引记录公共能力、提供方、调用方与边界类型。在“协议定义”下，每项能力使用一个三级标题和“字段、值”表，按契约顺序定义完整字段。协议标识用于索引、定义与验证责任之间的追溯。

类型声明或机器契约引用精确来源；协议还要明确数据与状态语义、失败、时序、生命周期和版本演进。纯查询无需虚构副作用或状态机，不适用的字段填写原因。

系统设计与接口协议以普通 Markdown 链接互相引用。本地引用使用相对路径，脚本检查存在的目标文件与明确支持的标题锚点。外部链接不发起网络验证。

## 执行结果

实际验证结果区分通过、失败、未执行与阻塞，说明必要的环境、步骤和证据。未执行或阻塞说明原因，通过必须有实际依据，不以计划或历史结果代替。审查结论按照代码审查 Skill 的问题证据与优先级要求直接回复。

## 校验与门禁

通过本 Skill 的实际安装路径执行，可从任意工作目录调用，文档路径指向目标项目：

```bash
python3 -B <本 Skill 目录>/scripts/validate_documents.py --kind interface-protocol --file <文档路径>
```

退出码 0 表示格式检查通过，1 表示文档违规，2 表示无法读取文件、契约或调用参数错误。Design 只修正自己产物的格式错误；Implementation 或 Review 遇到输入错误只反馈阻塞。CI 接入需求只作为建议，实际工程配置归 Implementation。

脚本校验标题与章节、必要内容、表格字段和数据行、元信息与结果枚举、协议字段、占位符、代码围栏及本地行内链接。引用章节支持普通标题生成的锚点，不使用重复标题锚点、HTML 自定义锚点或引用式链接作为需要脚本证明的引用。

文档格式校验、设计落地校验和行为测试分别提供证据。格式通过不代表设计正确，不代表实现遵守设计，也不代表用户已经获得软件价值。项目设计调整不意味着可以修改 Skill 的格式契约、模板或工具；这些属于另行授权的 Skill 维护工作。不能为迁就错误输入放宽约束。

## 独立维护

输入文档的格式契约随本 Skill 保存；执行时不加载产出该文档的 Skill。执行时核对接受格式，不能修改 Skill 契约与工具来迁就输入；格式演进属于独立的 Skill 维护任务，不在项目 Design、Implementation 或 Review 内执行。文档契约自带，基本检查按工作流使用 SWE 包内共享脚本。随 SWE 包使用时保留模块内资源及工作流明确引用的共享检查脚本。
